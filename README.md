# FindIT: Campus Lost and Found System
A front-end web application that helps students and faculty report, search, and browse lost and found belongings within the campus.

## Problem
- Students and faculty on campus frequently lose personal belongings (such as IDs, wallets, phones, and keys) and rely on scattered class group chats, social media posts, or word-of-mouth to find them.
- Unorganized reporting channels make lost-and-found information hard to search and update, while finders struggle to notify the rightful owners.

## Target Users
- College students looking to search for and recover their lost personal belongings on campus.
- Faculty members (and students) looking to report found items and help return them to their owners.

## Solution
A centralized, mobile-friendly web interface where the campus community can browse reported items, filter by category or status, view item details in a modal, and submit new lost-or-found reports saved in browser LocalStorage.

## Main Feature
Users can browse, search, and report lost and found campus items in one organized place.

## Pages
- Homepage (`index.html`): Welcomes users, explains how FindIT works, and provides quick navigation to browse or report items.
- Lost & Found (`lost-found.html`): Displays reported items with a search bar, category/status filters, and a detail modal.
- Report Item (`report.html`): Contains a validated form where users submit lost or found item details and photos.
